### Autocad MCP

<a href="https://github.com/mustafamertakceylan/Autocad-MCP"><img src="https://raw.githubusercontent.com/mustafamertakceylan/Autocad-MCP/main/desktop/assets/autocad-mcp-logo.png" align="right" width="80" alt="Autocad MCP logo" /></a>

Connect **Codex, Claude Code and OpenCode** to AutoCAD through a local MCP bridge. **52 CAD tools** for drawing, inspection, dimensions, solids and PDF output, with a system tray app and setup guides.

**Windows x64 preview · Full AutoCAD 2027 · Apache-2.0**<br />
C++ · TypeScript · Node.js · ObjectARX · CMake

Unsigned Windows preview; Mac support is planned. The app UI is Turkish, with English and Turkish documentation. Claude Code setup is included; live Claude model testing is pending.
